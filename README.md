# PCA and Clustering – US Arrests Dataset

This project explores crime data across US states using the US Arrests dataset (1973). The dataset includes arrest rates for murder, assault, and rape, along with the percentage of the population living in urban areas.

The analysis begins with data exploration and correlation analysis to understand relationships between variables. Strong positive correlations are observed between the different crime rates, indicating overlapping patterns in the data.

To simplify the dataset, Principal Component Analysis (PCA) is applied to reduce dimensionality while retaining most of the important information. The first two principal components capture the majority of the variance and provide a clear representation of the data structure.
